# Bhavya Duneja - Portfolio Website

A modern, interactive portfolio website showcasing my journey as a Software Engineer from Delhi to Osaka.

## 🚀 Features

- **Interactive Design**: Smooth animations and micro-interactions using Framer Motion
- **Responsive Layout**: Optimized for all devices with mobile-first approach
- **Modern Tech Stack**: Built with Next.js 14, TypeScript, and Tailwind CSS
- **Golden Ratio Design**: Implemented throughout for aesthetic perfection
- **Performance Optimized**: Fast loading with optimized images and code splitting
- **SEO Friendly**: Meta tags and structured data for better search visibility

## 🛠️ Tech Stack

- **Framework**: Next.js 14 with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Deployment**: Vercel (recommended)

## 📱 Sections

1. **Hero**: Interactive introduction with animated elements
2. **About**: Personal story and journey visualization
3. **Experience**: Professional timeline with detailed work history
4. **Projects**: Showcase of key projects with interactive cards
5. **Skills**: Technical expertise with animated progress bars
6. **Achievements**: Certifications and career milestones
7. **Contact**: Modern contact form with social links

## 🎨 Design Principles

- **Golden Ratio (1.618)**: Applied throughout for perfect proportions
- **Color Palette**: Green and white theme with leaf-inspired accents
- **Typography**: Inter and Poppins fonts for modern readability
- **Spacing**: Consistent golden ratio spacing system
- **Animations**: Subtle and purposeful micro-interactions

## 🚀 Getting Started

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Run Development Server**
   ```bash
   npm run dev
   ```

3. **Build for Production**
   ```bash
   npm run build
   npm start
   ```

## 🌟 Customization

The portfolio is designed to be easily customizable:

1. **Personal Information**: Update in each component
2. **Colors**: Modify in `tailwind.config.js`
3. **Content**: Edit component files directly
4. **Animations**: Adjust Framer Motion configurations
