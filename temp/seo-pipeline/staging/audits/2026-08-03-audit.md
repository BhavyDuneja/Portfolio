## Consistency finding (recurring)

The services page **head metadata + Offer schema still sell the old AI/SaaS model** while the visible content and homepage sell embedded experts. For GEO this matters more than for classic SEO: AI engines ingest title/meta/schema heavily and may describe AnantaSutra as "an AI voice-agent company" (this is exactly how one AI-summarized search described the brand today, based on an old cause-marketing blog post — see today's geo report).

## Top 3 prioritized fixes

1. **Rewrite /services title tag + meta description + Offer schema** to the embedded-experts model (e.g., "Hire Dedicated Embedded Experts — Pay Just the Salary | AnantaSutra"). Highest GEO impact; the metadata directly contradicts current positioning.
2. **Shorten homepage title to ≤60 chars** (e.g., "AnantaSutra — Embedded Experts, Pay Just the Salary") and trim meta description to ≤155 chars.
3. **Add FAQPage schema** to homepage or a pillar page (questions like "what is an embedded expert", "how fast can you start") + descriptive alt text on hero/logo images.
